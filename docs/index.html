La idea: especializarse y surtirse entre negocios

El mayoreo entre tiendas no es sólo comprar más barato: permite que cada negocio se concentre en lo que sabe hacer y complete su tienda con lo que otros hacen mejor, sin perder el crédito de quien produce.

  1. Cada tienda declara su especialidadQué produce (bordado a mano, cerámica, tostado de café) y qué quiere surtir con otras tiendas.
  2. Mercado sugiere conexionesProveedores para lo que te falta y compradoras para lo que produces, según esas declaraciones.
  3. Se aprueba la relación comercialQuien provee decide a quién le muestra sus precios por volumen. Los escalones son por piezas.
  4. Pedido de mayoreoCon inventario descontado, mensajería de la transacción, factura y 5 % de comisión.
  5. Reventa con crédito al tallerLa mercancía recibida se publica en la tienda compradora con un clic; la ficha dice quién la elabora.
  6. Se mide la especializaciónEl panel muestra qué parte del catálogo produce la tienda y qué parte surte con aliadas.

Cómo correrlo

La aplicación es dinámica (Server Actions y base de datos), así que esta página de GitHub Pages es un recorrido estático. Para usarla de verdad basta con clonarla:

git clone -b claude/lucid-meitner-eebxnm https://github.com/to49ra16s7azr9u2-cmd/mercado.git
cd mercado
npm install
npm run seed     # base de datos de ejemplo
npm run dev      # http://localhost:3000

Cuenta de demostración: demo@mercado.mx / demo1234. Las demás cuentas de ejemplo usan mercado1234.

Nota honesta: este sitio de GitHub Pages sirve archivos estáticos, por lo que aquí no corren las Server Actions ni la base de datos. Las capturas de arriba son de la aplicación real en ejecución, y la prueba end-to-end (npm run test:e2e) recorre 27 pasos: desde registrarse y comprar hasta abrir tienda, surtirse en mayoreo, revender con crédito al taller, consolidar envíos y pedir un adelanto.

日本語での概要

メルカリ相当の機能をひととおり備えたクローンのメキシコ版です。配色は LINE グリーン（#06C755）、UI はメキシコのスペイン語、通貨は MXN。

フリマ機能（C2C）

出品・検索・いいね・コメント・値下げ交渉・購入・取引メッセージ・発送通知・受取評価・相互評価・売上金・ポイント・クーポン・本人確認・通知設定。

Mercado Shops（メルカリShops 相当）

事業者登録（RFC等の審査）、在庫とバリエーション管理、複数個購入、ショップ運営ダッシュボード、特定商取引法にあたる「Información del vendedor」表示。

業者間の卸売ネットワーク

各店が「自分の専門」と「仕入れたいもの」を宣言 → 取引先マッチングと承認 → 数量別卸価格での発注 → 仕入れた商品を自店に再出品（生産者クレジット付き）→ 専門特化率の可視化。

共同オペレーション

共同集荷による配送費削減、コレクティブ（市場・商店街単位の共同出店）、店舗横断クロスセルクーポン、売掛金の前払い、CSV 一括取り込み。
